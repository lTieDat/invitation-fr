# Thiệp mời first date

Trang tĩnh responsive dành cho Trần Thị Ngọc Anh. Mở `index.html` để xem tại máy.

## Cập nhật thông tin buổi hẹn

Thông tin hiện tại: 20:00 thứ Năm, 15/10/2026 tại Highlands Coffee Five Star Kim Giang. Sửa hai mục `THỜI GIAN` và `ĐỊA ĐIỂM` trong `index.html` khi kế hoạch thay đổi.

Workflow `.github/workflows/pages.yml` triển khai trang từ nhánh `main` lên GitHub Pages. Repo cần bật Pages và chọn nguồn **GitHub Actions** lần đầu trong Settings → Pages.
